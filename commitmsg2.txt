Give the UI an ambient space identity

Second pass over the launcher. The first redesign was correct but generic;
this one commits to a look. Engine untouched: only app/ and docs change.

- The space colour paints the whole screen instead of a 14dp dot: a radial
  glow behind the top of each screen plus the hero border, dot, chevron, FAB
  and the halo behind every app icon. All of it lives in view/base/Ambient.kt
  and is plain GradientDrawable work, so it stays cheap on a Moto G50.
- Hero header: overline, the space name at 27sp, count and position on a glass
  card that opens the picker.
- Glass surfaces: translucent fill with a gradient hairline border, accent
  tinted where it matters. No RenderEffect blur.
- Motion: staggered grid and sheet entrances, press scale on tappable rows via
  stateListAnimator, glow crossfade and text rise on space change, slide-in for
  the add bar.
- Space picker: gradient colour chips, the active space outlined in its own
  colour with an "Atual" pill, sheets forced expanded and measured before being
  attached so the pinned footer clears the navigation bar.

Fixed while testing on the device: the glow had a hard edge where its view
ended (the gradient radius now matches the view height), and the foreground on
an accent is picked by luminance so the amber FAB gets dark text.
